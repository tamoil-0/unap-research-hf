# UNAP Research Semantic Recommender

API basada en FastAPI + FAISS para recomendación semántica de tesis y artículos académicos.

## Endpoints principales

- `/health`
- `/recommend`
- `/items/{uuid}`
- `/topics/top`

Construido para Hugging Face Spaces usando Docker.
